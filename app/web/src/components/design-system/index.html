Standard Margins

Minimum 2rem (32px) margins are used around all major layout containers to preserve the "Editorial" whitespace that distinguishes the system.

Tonal Layering

Instead of drop shadows, elevation is indicated by background shifts. Surface container lowest (#FFFFFF) is used for active focus, while Surface (#FBF9F8) is the base.
